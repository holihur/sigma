# Mobile checkout review

1. Keep the primary action above the fold.
2. Show the order summary before payment.
3. Use the project's sky-blue primary token and 12px control radius.
4. Put a back link on every step.
5. Keep touch targets at least 44px.
6. Verify the empty, loading, and error states.
7. After editing, call `get_design` and confirm the frame hierarchy.
