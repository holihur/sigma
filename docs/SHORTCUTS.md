# 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 移动 / 手型 | `V` / `H` |
| Frame / 矩形 / 椭圆 | `F` / `R` / `O` |
| 直线 / 钢笔（矢量） | `L` / `P` |
| 文本 / 评论 | `T` / `C` |
| 放置图片 | `⇧I` |
| 撤销 / 重做 | `⌘Z` / `⇧⌘Z` |
| 复制 / 剪切 / 粘贴 | `⌘C` / `⌘X` / `⌘V` |
| 原位粘贴 | `⇧⌘V` |
| Alt + 拖拽复制 | `Alt` + 拖拽 |
| 复制 / 粘贴样式 | `⌘⌥C` / `⌘⌥V` |
| 复制图层 / 删除 | `⌘D` / `⌫` |
| 重命名图层 | `F2` / `⌘R` |
| 隐藏 / 显示 | `⇧⌘H` |
| 锁定 / 解锁 | `⇧⌘L` |
| 分组 / 取消分组 | `⌘G` / `⇧⌘G` |
| 用 Frame 包裹 | `⌘⌥G` |
| 命令面板 | `⌘K` / `⌘/` |
| 查找 / 替换文本 | `⌘F` |
| 取消选择 / 逐级退出 | `Esc` |
| 方向键微调 / `⇧` 加速 | `←↑→↓` / `⇧+方向键` |
| 缩放 | `⌘ + 滚轮`、`+` / `-` |
| 适应画布 / 缩放到选中 / 100% | `⇧1` / `⇧2` / `⇧0` |
| 平移 | `Space` + 拖拽、中键拖拽、`H` |
| 完成钢笔路径 | `Enter` / 双击 |
| 闭合钢笔路径 | 点击起点 |
| 取消钢笔路径 | `Esc` |
| 矢量加锚点 | 双击路径 |
| 矢量删锚点 | `Alt` + 点击锚点 |

> 工具快捷键在编辑器未聚焦文本输入时生效。完整列表也可在编辑器右上角 **⋯ → Keyboard shortcuts** 查看。
